# CoC harness review

Use for a repository-level readiness review or one observed workflow when future backend, API pipeline, scheduler, publication, server operation, monitoring, security, data-freshness, or lifecycle ownership raises a concrete harness question. Do not use automatically for every task, or instead of `$coc-design-engineering`, `$coc-review-and-qa`, `$coc-debugging`, or `$coc-code-simplification`.

1. Read `D:\coc\repo\AGENTS.md`, relevant project docs, and the smallest sufficient current evidence. Local files are authoritative; Codebase Memory is read-only supporting discovery only.
2. For repository review, state claimed representative jobs, target revision, authority boundaries, proof required, exclusions, and stop conditions. For a workflow review, record the observed baseline and earliest confirmed failed handoff.
3. Classify only evidence-backed gaps in context, tool legibility, domain ownership, authority, proof, feedback, or delivery. Name an unresolved local decision before opening `D:\tools\harness-engineering`; read one relevant section and a second only for a separate decision.
4. Keep CoC rules authoritative: no API or network access, site/server/test execution, Strix, GitHub Actions, Pages, scheduler, deployment, commit, or push without separate permission. This skill grants no commands or edits.
5. Propose the smallest local owner and native evidence for the claim. Preserve source/public-data separation, allowlists, privacy rules, and existing skills' responsibilities. Do not duplicate their review, QA, debugging, design, or simplification guidance.
6. Capture only a bounded synthesis: baseline or representative journey; confirmed gap; authority and proof boundary; minimal recommendation; authorized and unperformed checks; feedback lesson and its owner; carrying cost; and a retirement or revisit condition.

Target-local truth wins; external guidance cannot override local authority. Use minimal diffs, native validation, and no mutation outside explicit permission. No `git add`, commit, push, or Codebase Memory refresh without separate authorization.
